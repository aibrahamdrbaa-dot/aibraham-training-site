# Aibraham Training Website\n\nPremium RTL static website for Aibraham — Practice AI for people and work.\n\n## Pages\n- `/` — Home\n- `/course.html` — 16-session curriculum\n- `/about.html` — About Aibraham\n- `/verify.html` — Certificate verification\n- `/register.html` — Registration\n\n## Deployment\nThis is a dependency-free static site. Upload the repository to Netlify with the publish directory set to `.`.\n\n## Certificate verification\nQR links can use: `https://aibraham.com/verify/<verification-token>`\n\nVerification tokens are per certificate, not per person. Add future certificate records to `script.js` or move the records to a backend/database when the certificate volume grows.\n
